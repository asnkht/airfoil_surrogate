**Neural Network Surrogate Modelling for Airfoil Aerodynamic coefficient prediction**



**Overview:**

This project makes use of neural networks to predict the aerodynamic coefficients from airfoil geometry and flow conditions.



**Objectives:**

>Generate aerodynamic coefficients using XFOIL

>Develop a baseline regression model

>Train a deep neural network

>Evaluate prediction accuracy and generalisation to unseen airfoil geometries

>Compare model time vs aerodynamic solver times



**Input:**

>Airfoil geometry

>Angles of attack

>Reynolds number



**Output:**

Drag coefficient(cd) 

Lift coefficient(cl)
